Simulator

A whole TinCAN bus, offline. This runs the same physical layer and state machine the live apps use — real tone generation, real Goertzel detection, real bit clocks — over a simulated room with per-path propagation delay, distance attenuation, noise and a reverberant tail. No microphone, no second device, and it is deterministic, so you can watch a specific arbitration happen the same way twice.
