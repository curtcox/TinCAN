Pair test

Two Console nodes, ada and bob, run in this one tab and share this device's speaker and microphone. They join the main bus, ada proposes a side link and bob judges and accepts it as the Console would, they send a message each way over the link, and ada closes it (Part 2 §8). Each step is checked as it happens. Running both nodes in one tab avoids the browser silencing one tab's audio when another starts a stream, which stops two Console tabs testing a link. Each node hears the other exactly as loudly as itself, so this tests the protocol and the browser's audio, not distance.
