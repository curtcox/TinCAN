Snooper

A passive TinCAN analyzer. It listens on the microphone, recovers the bit clock, decodes frames, and shows you the physical layer while it does it. It conforms to the Listener profile of spec §9.1: it never transmits, so it never acknowledges, and every frame it decodes is destroyed by the transmitter's acknowledgement-error flag. That is expected — see the note below the frame list.
