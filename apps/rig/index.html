Rig device

This page is one device of a TinCAN test rig. It joins the server once, then runs the descriptions the server sends: it plays their tones on a shared clock, records its microphone, measures latency, noise and its own audio, and can join the bus as a node. It executes descriptions, not code.

The device's own ceiling: descriptions are limited to 50%, and this caps them lower.
