Self-test

Runs two real Console nodes — the same AudioWorklet, Modem and Session code — inside this browser, wired to each other through a simulated room instead of a speaker and microphone. It needs no microphone, makes no sound, and takes a few seconds. If it passes, this browser can run a node, and any trouble between two devices is in the air between them, not in the browser.

Microphone check

The test above leaves out the air. This measures it: it plays about five seconds of tones on this device's speaker, at the Console's transmit level, and records what its own microphone hears. Set the volume where you will use the Console, and keep the room quiet. Then, to compare with a second device, press Listen here and Measure this device on the other one, placed where it will be when you use the Console.
